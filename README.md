# Task Manager

A simple and responsive **Task Manager** app built with **React**, **Vite**, and **Tailwind CSS**.  
Manage your daily tasks efficiently by adding, updating, and deleting tasks.

---

## Features

- Add new tasks
- Mark tasks as completed
- Edit tasks
- Delete tasks
- Responsive design with Tailwind CSS

---

## Technologies

- **React**  
- **Vite**  
- **Tailwind CSS**  
- **JavaScript (ES6+)**
